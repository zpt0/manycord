# Security

## Reporting Security Issues

If you discover a security issue in Manycord, please report it responsibly by:

1. Opening a private issue in the GitHub repository (if you have access)
2. Emailing the maintainers at manycord@users.noreply.github.com
3. Following responsible disclosure practices

## What We Consider a Security Issue

- Any vulnerability that could expose Discord user data
- Code that could be used to bypass account verification
- Issues that could compromise Discord session security

## Security Policy

We will investigate all reported security issues and respond appropriately. Critical security issues will be addressed promptly in future releases.
